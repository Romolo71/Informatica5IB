# Algebra Relazionale - Parte 1

Esercizi introduttivi sull'**algebra relazionale**, realizzati durante il corso di Informatica della classe 5IB.

## 📚 Argomenti

In questa prima parte vengono affrontate le principali operazioni dell'algebra relazionale:

- **Selezione** (`σ`) per filtrare le tuple di una relazione;
- **Proiezione** (`π`) per selezionare determinati attributi;
- **Prodotto cartesiano** (`×`) per combinare le tuple di due relazioni;
- **Join** (`⋈`) per mettere in relazione tuple appartenenti a relazioni diverse sulla base di una condizione comune;
- combinazione di più operatori per costruire interrogazioni più complesse.

## 📁 Struttura

La cartella contiene esercizi dedicati all'utilizzo degli operatori fondamentali dell'algebra relazionale.

Gli esercizi permettono di applicare le diverse operazioni a relazioni e condizioni differenti, passando dalle interrogazioni più semplici alla combinazione di più operatori.

## 🎯 Obiettivo

Lo scopo degli esercizi è comprendere il funzionamento dell'algebra relazionale e imparare a costruire interrogazioni sui database relazionali utilizzando **selezione, proiezione, prodotto cartesiano e join**.
